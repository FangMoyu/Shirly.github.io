# synchronized 的使用和特性

在 Java 里，synchronized 是经常遇到的并发工具。理解它，最好先从“锁住的对象是谁”开始。

## 三种常见场景

普通实例方法锁住当前对象，静态方法锁住对应的 Class 对象，代码块则锁住括号里明确指定的对象。锁对象不同，并发行为也会不同。

```java
public synchronized void update() {
    // 当前实例作为锁对象
}

public void updatePart() {
    synchronized (this) {
        // 只保护这一小段临界区
    }
}
```

## 需要记住的特性

- 有序性、可见性和原子性是理解锁机制的三个入口。
- synchronized 具备可重入性，同一线程可以再次获得自己持有的锁。
- 锁的范围越大，保护越完整，但等待也可能越多。
